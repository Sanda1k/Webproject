Gastro Chef — сервис доставки здорового питания
Сквозной индивидуальный учебный проект по дисциплине «Веб-программирование».

- Название проекта: Gastro Chef
- Идея и назначение: Сервис ежедневной доставки правильного и сбалансированного питания с возможностью выбора программ, подсчетом КБЖУ и оформлением заказов.
- Текущее состояние: Реализована семантическая HTML5-структура главной страницы (без CSS и JS), подготовлены Product Brief и семантическая карта.
- Дизайн-макет проекта: https://www.figma.com/design/MacGFpmxh0nGZn3o5q3IzL/Gastro-Chef--?node-id=0-1&p=f&t=rCiXxnpMbZV3qzNF-0
- Автор: Газизуллин Азат Рустемович

Инструкция по запуску
1. Склонировать репозиторий
git clone https://github.com/Sanda1k/Webproject.git
2. Перейти в рабочую ветку:
git switch lab/02-html
3. Открыть файл `index.html` в браузере (или через расширение Live Server в VS Code).
